↓

iPhoneユーザー辞書の使い方　〜メルカリの出品が楽になる方法〜



メルカリで、商品名や商品の説明を書くときに定型文を用意しておくと出品が楽になる。たとえば、「メモ」アプリに書いておいてコピーをするのも一つの手だが、結構面倒くさい。そこでユーザー辞書を使うと便利。

iPhoneのユーザー辞書とは、よく使う言葉や長い文章を短い読みで一発入力できる機能。
僕は、マジック・ザ・ギャザリングのカードを出品しているが
「mt」→マジック：ザ・ギャザリング
「mg」→トラブル防止のため〜
と出るようにしている。

登録方法

iPhone
設定
　一般
　　キーボード
　　　ユーザー辞書
　　　　右上の「＋」をタップ
　　　　　単語：呼び出したい文章を書く
　　　　　よみ：上の単語を呼び出す文字を設定する
上の例で言うと
単語：マジック：ザ・ギャザリング
よみ：mt
　　　　　設定したら右上の「保存」をタップ

これで、上の例だと「mt」と打って「return」をタップすれば、マジック：ザ・ギャザリングと入力される。

メルカリだと、出品物が違っても商品の説明は
中古品ということを認識した上でお願いします。神経質な方は購入を控えてください
的なことを書くと思う。そういうのを登録しておくと楽である。

使ってみて良かったiOSアプリ



Apple純正アプリは除く。
あえて言うなら「メモ」と「Numbers」と「GarageBand」の三つが特に好き。

本題。

完全無料アプリ編

「Just Full Screen Cam」
iPhoneのカメラで映ったものを映し出すだけのアプリ。
「カメラ」と違ってUIが一切ないので配信で映すのに向く。
注意点として、自動ロックの影響を受けるので、自動ロックをなしにしないと途中で落ちる。

無料アプリ編

「InShot」
YouTubeショート動画を作るのに便利。
横画面を縦画面に変換することだけに使うのなら広告を流す必要があるが、無料で使えるし面倒なこともない。

有料アプリ編（価格は2026年1月現在）

「Procreate Pocket」：1,000円
お絵描きアプリ。
お絵描きアプリは色々あるが、有料でも広告があるものが多い。
このアプリは広告が一切ない。
取り消し（アンドゥ）の方法は二本指タップである。
二本指で広げたり縮めたりで拡大縮小。
二本指で回転で絵の回転。
他にもあると思うがこれだけでそこそこの絵が描ける。

「Flink」：300円
ToDoリストを作るものだけど、メモ帳として便利。
やりたいことを思いついた時に羅列しておくと、後でアイデアを思い出したりできる。
メモでもいいけど、それぞれごとにチェックをつけられるのが便利だし、日付ごとに分かれるのも便利。

「ターボスキャンプロ」：700円
スキャナがわりになるアプリ。スキャナ要らず。嵩張るからね。
ある程度正確で文章を残したい時に便利。
僕はレトロゲームの説明書の操作方法の部分だけを映して保管するために使っている。

「Whisper Notes」：800円
買い切りで使える文字起こしアプリ。
一回使ってみたが、精度はあまり高くなかった。
これを使って副業ができるらしい。僕はたまたま無料だったので使っただけ。

2025/10/14


iMovieの基本的な使い方メモ



メディアを読み込む
　動画、画像、音楽をiMovieに追加する
　左上の「メディアを読み込む」をクリックして選択してもいいが、その部分に直接ファイルをドラッグして取り込むこともできる。

タイムラインにクリップを配置
　インポートした素材（動画や音楽など）を、下部のタイムラインにドラッグ＆ドロップして、順番を決めて配置する。

基本的な編集
　クリップを選択して、タイムラインの端をドラッグすることで、長さを調整できる。
　不要な部分を削除するには、クリップを分割（Command + B）して切り取る。
　クリップの下にある音量バーを使って、音声の音量やフェードイン/フェードアウトを設定できる。

トランジションの追加
　クリップ間（動画と動画の間）にトランジション（切り替え効果）を追加できる。
　タイムライン上でクリップ間にドラッグ＆ドロップして追加する。

保存
　「ファイル」→「書き出し」から動画を保存できる。





iMovieに画像を設置する方法

そのまま画像をタイムラインにドラッグすると、「下から上にスライドして出る」アニメーションが適用される。
これを解除する。

画像クリップを選択した状態（黄色の枠がついた状態）で、二重四角形みたいな形のアイコン「ビデオオーバーレイ設定」をクリック。
右側のプルダウンから「ピクチャインピクチャ」を選ぶ。
範囲を指定するようなアイコン「クロップ」をクリック。
スタイルを「フィット」にする。
これで画像が固定表示される。

二重四角形みたいな形のアイコン「ビデオオーバーレイ設定」をクリックした状態ならば、画像を動かしたり拡大や縮小ができる。

2025/9/5


CSS flexboxメモ



今まで、要素を横に並べるときにfloatを使っていたが、flexboxを使うのが現代の主流らしい。というより、crearfixみたいなバグ技みたいなことをしないで済むのでコード自体もスッキリする。
この方法は、ChatGPTに指摘されて習得した方法である。
余談だが、ここ数年で買った書籍ではfloatを使ってレイアウトする手法が書いており、僕は無駄な知識を覚えたことになる。そして、このサイトの修正をすることになった。はじめから使っていれば手間もかからなかったわけである。正直、もう書籍で何かの技術を学ぶのはリスクしかない。この件然り、Python然りである。書籍は一冊を残して捨てる。このメモで十分である。



本題。
flexboxに使うcssをメモ的にまとめた。
これで、一通りのレイアウトができるはず。



| 用語                     | 意味               | 備考                           |
| ーーーーーーーーーーーーー | ーーーーーーーーーーーーー | ーーーーーーーーーーーーーーーーーー |
| display: flex          | ブロック要素の flexbox  | 幅いっぱい使う横並びに最適            |
| display: inline-flex   | インライン要素の flexbox | 他のテキストと同じ行に並べたいとき     |
| gap                    | 子要素間の間隔          | margin 代わりに便利（ただし、flexbox内のみ）|
| flex-direction: column | 子要素を縦に積む         |  |

1. フレックスボックス（flexbox）＝かたまりのイメージ

「親要素が flexbox になると、その中の子要素が flex のルールで並ぶかたまり」 と考えるとわかりやすい

ルールの例：

デフォルトは横方向に並ぶ（row）

flex-direction: column で縦に並ぶ

justify-content で主軸方向（横or縦）の間隔を調整

align-items で交差軸（縦or横）の位置揃えを調整

なので、「かたまりをブロック要素にするかインライン要素にするか」という認識で正しい。

display: flex → 親要素がブロックのように振る舞う flex のかたまり

display: inline-flex → 親要素がインラインのように振る舞う flex のかたまり

2. gap は flexbox 内だけ？

基本的には flexbox の子要素同士の隙間専用

これだけで「均等なスペース」が簡単に作れるので便利

子の個別調整や外側の余白は margin で設定する

だし巻き卵を作ってみた



とりあえず作ってみて、美味しかったので
その時のレシピと作り方を書く。

ちなみに、だし巻き卵は
溶き卵に出汁を混ぜて焼き固める料理
とあるが、出汁は、ほんだしを溶かした水で代用できる。

余談だけど、小さじって一番小さいスプーンのことだと思ってた。
2.5SPOONって書いてあるんだけど、これ小さじじゃなかった件・・・
茶さじ言うらしい。
ちなみに、小さじは上記2.5SPOON×2杯を指す。

〜〜〜材料〜〜〜

水:100ml
卵:3個
ほんだし:小さじ1
しょうゆ:小さじ1
みりん:小さじ1



〜〜〜作り方〜〜〜

1.水にほんだしを入れて溶かす。
水を測るのに計量カップを使うと思うけど
そのまま他の材料を入れることにより片付けがラクになる。

2.卵3個、しょうゆとみりんを加え、かき混ぜる。

3.上記のものを油を引いた卵焼き器に適量を流し弱火で焼く→巻くを繰り返す。
やろうと思えば、フライパンでも代用できる。
僕個人の問題でもあるけれど、油が苦手なのであまり引きたくない。
油を使わないのは当然焦げるのでダメである。
なので、初回は油を引き、次は鍋に油が残っているので
油を引かずにそのまま焼くを繰り返したところ、コゲつかなかった。



以上。



僕の技量不足というか知識不足というか、巻き方がよくわからん・・・
鍋の向こうから手前に巻いたり、逆も試したものの上手くできんかった。
それでも、適当にやれば何とかなる。
形は不恰好だけど・・・

    「アドレス」→inetアドレス、IPv4アドレスを入れる(※参照)。
    「ネットマスク」→サブネットマスク
    「ゲートウェイ」→ルーター
  「DNS サーバー」→ゲートウェイと同値
入力したら保存をクリック。



※アドレスの決め方

Aterm MR03LNでMVNO回線を使用しているときは
前回記事の数値を推奨。

今使っているアドレスで固定するのが手っ取り早い。
今のIPアドレスの確認方法。

・Windows
コマンドプロンプトで「ipconfig」

・Mac
「システム環境設定」→「ネットワーク」
  →「詳細」→「TCP/IP」のIPv4アドレス

・Ubuntu
端末で「ifconfig」
その中のinetアドレスが該当。
