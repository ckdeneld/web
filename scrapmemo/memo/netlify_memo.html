Netlifyメモ



Netlifyとは
ウェブサイトスペースとして使える場所。他の便利な機能もあるらしいが、ウェブサイトスペースとして使うためのメモを書いていく。



GitHub Pagesとの違いとして
公開されたウェブサイトの右下に「Powered by Netlify」という文字が出る。
更新の仕方も常に上書きする方法なので使いにくいイメージ。
それなりのサイトなら、GitHub Pagesの方が良いと思う。



デプロイとは
ウェブサイトを公開するためにファイルをアップロード・配置すること。
Netlifyでは、ウェブサイトのファイルを塊としてアップロードするのだけど、その公開単位をデプロイとして扱う。



新規登録
https://app.netlify.com/signup
ログイン
https://app.netlify.com/login



ファイルアップロード
「Want to deploy a new project? Drag and drop your folder here.」
と書かれているところにファイルを直接ドラッグすればいい。

アップロードしたファイルは「Projects」にまとめられる。



ファイル削除
消したい「Projects」をクリックする。
　「Project configuration」をクリック。
　　上部タブの「Configuration」をクリック。
　　　「Delete this project」をクリック。



サイト公開
公開したい「Projects」をクリックする。
　左にある「Visitor access」をクリック。
　　「Edit visibility」をクリック。
Visibility：Public



URL変更
変更したい「Projects」をクリックする。
　「Project configuration」をクリック。
　　上部タブの「General」をクリック。
　　　「Change project name」をクリック。
変えたい文字列にして「Save」
https://〇〇.netlify.app
〇〇の部分を変えられる。



サイト更新
更新したい「Projects」をクリックする。
　下の方にある「Activity」欄の中の「All deploy activity　＞」をクリック。
「Deploys」のところにファイルを直接ドラッグする。

古いデプロイの削除
「Activity」欄の中にある古いデプロイをクリックする。
（「Published」のマークがあるやつが公開されているもの。つまり、マークがついていないものを選ぶ）
　「Options」をクリック→「Delete deploy」をクリック
　　「Delete」
